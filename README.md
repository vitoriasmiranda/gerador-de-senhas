# Gerador de Senha Inteligente

Este projeto oferece um formulário de cadastro com um recurso integrado de geração de senhas seguras. Ele permite que os usuários criem facilmente contas e, ao mesmo tempo, gerem senhas robustas com base em critérios personalizáveis, como comprimento, inclusão de letras (maiúsculas e minúsculas), números e símbolos.

---

## Funcionalidades

* **Formulário de Cadastro:** Interface para registro de nome, e-mail e senha.
* **Gerador de Senha:** Funcionalidade interativa para criar senhas fortes.
* **Personalização da Senha:**
    * Definição do **comprimento** da senha.
    * Inclusão/exclusão de **letras** (minúsculas e maiúsculas).
    * Inclusão/exclusão de **números**.
    * Inclusão/exclusão de **símbolos**.
* **Exibição da Senha Gerada:** Mostra a senha gerada de forma clara.
* **Copiar Senha:** Botão para copiar a senha gerada para a área de transferência com um clique.
* **Validação (Básica):** Campos de nome, e-mail e confirmação de senha (embora a validação completa seja apenas visual no HTML neste momento).

---

## Tecnologias Utilizadas

* **HTML5:** Para a estrutura semântica do formulário e da página.
* **CSS3:** Para estilização, layout responsivo e design visual do gerador e do formulário.
* **JavaScript (Vanilla JS):** Para toda a lógica interativa:
    * Geração de caracteres aleatórios.
    * Combinação de tipos de caracteres na senha.
    * Manipulação da visibilidade do gerador de senha.
    * Funcionalidade de copiar para a área de transferência.
* **Google Fonts (Montserrat):** Para uma tipografia moderna e agradável.

---

### Instruções de Uso:

* Preencha os campos de **Nome**, **E-mail** e **Senha**.
* Para usar o gerador de senha, clique em **"Quer ajuda para criar uma senha segura? Clique aqui."**.
* Ajuste as opções de **Quantidade de caracteres**, **Letras**, **Números** e **Símbolos** conforme sua preferência.
* Clique em **"Criar senha"** para gerar uma senha.
* Clique em **"Copiar"** para copiar a senha gerada para a área de transferência.
* Preencha o campo **"Confirmação de senha"** com a senha desejada (ou a senha gerada).
* Clique em **"Cadastrar"** para simular o envio do formulário.
